# Mini Shopping Website

A small vanilla JavaScript shopping website project that demonstrates a simple product catalog, cart interactions, and responsive layout.

## Features

- Product listing with add-to-cart functionality
- Shopping cart summary and quantity updates
- Responsive layout for desktop and mobile
- Built using HTML, CSS, and JavaScript only

## Technologies

- HTML
- CSS
- JavaScript

## Usage

1. Browse the available products.
2. Add items to the cart.
3. View or update the cart contents.
